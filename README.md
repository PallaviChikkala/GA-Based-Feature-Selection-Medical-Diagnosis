# GA-Based Feature Selection for Medical Diagnosis

## Project Overview
This project uses a Genetic Algorithm (GA) for feature selection
and Logistic Regression for breast cancer classification.

## Dataset
Breast Cancer Wisconsin Diagnostic Dataset
- Samples: 569
- Original features: 30
- Classes: Malignant and Benign

## Experimental Results
- Accuracy: 96.49%
- Balanced Accuracy: 96.73%
- Precision: 98.57%
- Recall: 95.83%
- F1-score: 97.18%
- ROC-AUC: 99.60%

## Feature Selection
The Genetic Algorithm selected 10 features from the original 30.
